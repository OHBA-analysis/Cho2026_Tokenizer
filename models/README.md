# Models

### 📌 Overview

This directory contains configuration files defining the architectures and training settings for the tokenizers, MEG-GPT models, and downstream decoding tasks (baseline, zero-shot, and fine-tuning). These files were used to generate the results reported in the manuscript.

The provided configurations serve as **examples**. Users must update file paths and directory references to match their local or institutional storage environments before running any training or evaluation scripts.
